# Hotel Management System

This is a simple **Java hotel management system** created as a software developer project.

The project focuses on managing hotel-related data using Java, JPA/Hibernate and MySQL.

## Technologies

- Java
- JPA
- Hibernate
- MySQL
- MySQL Workbench
- IntelliJ IDEA

What This Project Does

The project is a basic hotel management application that works with a MySQL database.

The basic process is:

Java Application
       ↓
JPA / Hibernate
       ↓
MySQL Database
       ↓
Hotel Data


Java is used for the application logic, JPA/Hibernate is used to work with the database and MySQL is used to store the application data.

Requirements

To run or modify this project you need:

Java
IntelliJ IDEA
MySQL
MySQL Workbench
Maven or the required project dependencies
Database

The project uses MySQL as the database.

Before running the application make sure that:

MySQL is installed and running
The required database is created
The database connection settings are configured correctly

Purpose

This project was created mainly for learning and practicing Java, JPA, Hibernate and MySQL.

It can also be used as a simple example for anyone who is starting to work with Java applications and relational databases.
